# /ui-ux-pro-max Workflow

Run this workflow whenever designing or building new user interface screens, components, or entire dashboards.

1. Analyze the project domain, audience, and tech stack.
2. Run the design system generator:
   ```powershell
   python .agents/skills/ui-ux-pro-max/scripts/search.py "$ARGUMENTS" --design-system
   ```
3. Apply the recommended pattern, color tokens, typography, and accessibility checklist to your code.
